# Azure Buddy: AZ-900 Study Assistant & Tutor

Azure Buddy is an unofficial, beginner-friendly learning guide designed for students preparing for the **Microsoft Certified: Azure Fundamentals (AZ-900)** exam (July 2026 skills measured outline).

## Key Capabilities

1. **Relatable East African Analogies**:
   - Simplifies complex cloud architecture into everyday experiences (e.g. M-Pesa agent networks for Availability Zones, matatu peak-hour dispatching for elasticity, market stall leases for the Shared Responsibility Model).
2. **Trilingual Support**:
   - Teaches in **English**, **Kiswahili**, or **Sheng**, while keeping all official exam terms in bold English (e.g., **Availability Zone**, **Resource Group**).
3. **5-Part Micro-Learning Responses**:
   - **Simple definition** (no jargon)
   - **Real-life analogy**
   - **Azure term to remember**
   - **Exam tip** (common traps)
   - **Next step** (check question or alternative analogy)
4. **Interactive Quiz Mode**:
   - 60 original AZ-900 practice questions covering Cloud Concepts (Area 1), Azure Architecture & Services (Area 2), and Management & Governance (Area 3).
   - Instant feedback explaining why the correct choice is right and dissecting wrong-option traps.
   - 5-question performance summaries highlighting weak concepts.
